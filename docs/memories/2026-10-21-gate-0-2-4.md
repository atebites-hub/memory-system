### Learnings
- Script: `check_path` and the agent branch of `on_post` record no root for an agent; new `leading_cd` (bare, single- or double-quoted dir, relative to the hook's cwd, must exist) feeds the busy mark in `on_post`. Lead events unchanged.
- Tests: 29 new checks (163 total under /bin/bash 3.2); 8 fail on 0.2.3's script. The lead-Bash and agent-memory checks are guards that pass on 0.2.3 by design. `t_stop_main_checkout_never_skipped` now records the main checkout with a lead edit, since the agent's edit no longer does.
- Both manifests at 0.2.4; README Agents bullet and script header updated.
- Review: no blockers. Header line and README line 7 now say the Bash root record is a lead's only. Rejected as inherent to the spec and fail-safe: `cd -P`/`cd --`/backslash-escaped dirs mark nothing (no general shell parsing); an agent whose cwd is already its worktree stays unseen; a read-only agent `cd` into another worktree also marks it busy.
